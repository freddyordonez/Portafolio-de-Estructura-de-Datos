## 🎯 Objetivo

Centralizar los trabajos de la asignatura en un único repositorio de GitHub, manteniendo una estructura clara que permita:
* Organizar las actividades por asignatura, unidad y trabajo.
* Conservar los archivos y evidencias correspondientes a cada actividad.
* Facilitar la revisión de los trabajos realizados.
* Mantener un historial de cambios mediante Git.

---

## 📂 Estructura del repositorio

La organización general del repositorio según los directorios actuales es la siguiente:

```text
Avance-Lista-Doble-Grupo4/
│
├── Unidad_1/
│   ├── AA's/
│   │   ├── AA_01/
│   │   ├── AA_02/
│   │   ├── AA_03/
│   │   └── AA_04_Avance4_ABP_Grupo04/
│   │
│   └── APE's/
│       ├── APE_01/
│       ├── APE_02/
│       ├── APE_03/
│       └── APE_04/
│       └── APE_05/
│
└── README.md
```
*Nota: El árbol representa las carpetas identificadas actualmente en el repositorio. Se actualizará conforme se incorporen nuevas actividades y unidades.*

## 📁 Organización de los trabajos

### 📦 `AA's` — Actividades Autonomas
Carpeta destinada a las actividades de aprendizaje desarrolladas durante la asignatura:
* **Unidad_1:** Actividades correspondientes a la Unidad 1.
* **AA_01, AA_02, AA_03:** Carpetas de las actividades de aprendizaje secuenciales.
* **AA_04_Avance4_ABP_Grupo04:** Carpeta correspondiente al avance del proyecto integrador (ABP).

📂 [Explorar actividades de aprendizaje](./Unidad_1/AA's)

### 🧪 `APE's` — Aprendizaje Práctica Experimental
Carpeta destinada a las actividades prácticas y experimentales:
* **APE_01, APE_02, APE_03, APE_04:** Carpetas correspondientes a las prácticas experimentales de la unidad.

📂 [Explorar actividades prácticas](./Unidad_1/APE's)

## 📊 Convenciones de organización

Para mantener el repositorio ordenado durante el ciclo académico, se propone utilizar las siguientes convenciones:

| Elemento | Convención |
| :--- | :--- |
| **Actividades de aprendizaje** | `AA_01`, `AA_02`, `AA_03` |
| **Actividades prácticas** | `APE_01`, `APE_02`, `APE_03`, `APE_04` |
| **Unidades académicas** | `Unidad_1`, `Unidad_2`, `Unidad_3` |
| **Documentación general** | `README.md` |

Se recomienda que cada actividad contenga sus respectivos archivos, códigos fuente, documentos y evidencias, según las instrucciones de entrega.
